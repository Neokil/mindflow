# Updating dependencies

Run `make upgrade` in a clean working tree with Go, Node/npm, Python 3, and network access available. It resolves current stable versions from official registries and releases, updates Go modules, npm dependencies and the manual demo/reel encoders, refreshes sqlc, golangci-lint, actionlint and govulncheck, and updates GitHub Actions and Docker image references. Actions remain pinned to full commit SHAs; images are pinned to registry digests. The final runtime remains `scratch`.

`make upgrade UPGRADE_FLAGS=--dry-run` resolves the reference changes without writing files or installing dependencies. `make upgrade UPGRADE_FLAGS=--full` additionally runs browser and Docker verification. The default runs generation, formatting/lint checks, tests, and vulnerability scans. Resolution or verification failures stop the command and leave the diff available for review. It never commits, pushes, or publishes.

Review the diff, compatibility changes, and [third-party notices](../../THIRD_PARTY_NOTICES.md) before committing. The upgrade script does not regenerate those notices: update dependency versions, attribution, and license text when dependencies change, including licenses carried with PDF.js support assets. Major npm and tooling releases are included and may require code changes. Go module major versions that require a new import path need an explicit migration; Go's normal module update rules apply. Runner operating systems and application configuration are not dependencies and are not changed automatically. Set `GITHUB_TOKEN` to avoid GitHub's anonymous API limits if needed. Python must have a working system CA trust store; do not disable certificate verification.

The password suggester bundles EFF's [Short Wordlist #1](https://www.eff.org/files/2016/09/08/eff_short_wordlist_1.txt), by the Electronic Frontier Foundation, under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Dice indices and the single hyphenated entry were removed; two or three words are sampled locally with Web Crypto and random punctuation, resampling whole words until the total length is 10–15 characters. See [EFF's passphrase guidance](https://www.eff.org/dice). Suggestions never call an external service.
