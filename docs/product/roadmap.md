# Planned improvements and features

These items are deferred; none has a committed release date. Current functionality is described in the [product definition](overview.md) and [user guide](../user-docs/using-mindflow.md).

| Improvement | Open questions |
| --- | --- |
| Canvas export | Choose formats and define treatment of infinite bounds, images, text, and comments. |
| Import from Linwood Butterfly | Investigate file-format compatibility and how faithfully supported content can be translated. |
| More shape types | Decide which shapes are useful and extend the existing shape tools without complicating the editor. |
| Simultaneous canvas writers | A possible future collaboration model; requires decisions about conflicts, synchronization, and recovery. The current model remains one writer per page. |

Proposals should identify the user problem, expected behavior, data and permission implications, and a small way to verify the result. Agreed changes belong here until shipped; once available, document their behavior in the user and developer guides.
